The thesis in one minute

MLflow is a thin Python client and Flask server in front of a pluggable backend. The same five primitives — Experiment, Run, Model, Registered Model, Artifact — flow through every layer. The GenAI platform reuses all of that and adds a sixth: the Trace. Once you internalise that, the entire codebase falls into place.

Architectural thesis

Don't build a parallel system for LLMs. Extend the one you already have. Trace is to a Run what Span is to a Metric — a richer, time-stamped, hierarchical observation, but stored, queried, and exported through the same machinery.

The map

LayerML platformAI / GenAI extension
Observation Run with metrics, params, tags Trace with span tree (LLM, tool, retriever, agent)
Packaging MLmodel with framework flavor + pyfunc ChatModel as a typed pyfunc subclass
Registry Registered models, versions, aliases (champion/challenger) Same — agents are registered models
Serving Pyfunc scoring server, /invocations Same server, plus the AI Gateway in front of provider APIs
Evaluation Numeric metrics on holdout sets Judges (LLM-as-judge + heuristics) producing assessments per row, linked to traces

How these guides talk

Throughout the architect and user guides, you'll see roundtables like this one — short dialogues between roles arguing through a tradeoff. They are the design conversations that should happen before you ship. The roles you'll meet:

The cast you'll meet in roundtables
A Architect /the long view
Cares about coherence, blast radius, and what the next migration costs.
D Storage /the truth
Cares about durability, throughput, and what your "just one more index" actually costs at 10× load.
M ML Engineer /the productionist
Cares about reproducibility, drift, and the thing the data scientist forgot to commit.
G AI Engineer /the agent wrangler
Cares about latency, cost-per-call, prompt versioning, and what the LLM did when no one was looking.
P Product Manager /the user voice
Cares about time-to-value, the demo on Friday, and that a feature exists at all.
S SRE /the pager
Cares about SLOs, blast radius, runbooks, and not being woken at 3am.
X Security /the threat model
Cares about secrets, PII, supply chain, and the audit log.
N Data Scientist /the explorer
Cares about velocity, notebook ergonomics, and not being told to use a JIRA ticket to log a metric.

How to deploy this site

Open any HTML file directly from disk in a browser — no build step. To publish on GitHub Pages, push architecture-docs/ to master; the workflow at .github/workflows/architecture-docs.yml serves the entire folder, including this static/ subdirectory, at /mlflow/static/.

Local preview

You can simply double-click index.html — no Jekyll, no Ruby, no bundle install. The pages are entirely self-contained: one shared styles.css, no JavaScript, no external assets. Works offline.
