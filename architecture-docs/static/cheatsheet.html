Cheat Sheet

Every key fact, one screen. Use as a last-minute revision pass; deeper context lives in the Architect Guide.

The 5 (6) primitives

  • Experiment — bucket of runs
  • Run — one execution; metrics + params + artifacts
  • Model — MLmodel manifest + weights
  • RegisteredModel + Version — named, versioned pointer
  • Artifact — any file logged to a run
  • Trace AI — tree of spans

Cross-cutting patterns

  • Store pattern — one Abstract, many backends
  • Flavor pattern — same trio for every framework
  • Client / service / store — 3-layer split
  • URI-routed registry — scheme picks backend
  • safe_patch — one monkey-patch util

Tracking storage

  • FileStore — YAML/JSON; dev only
  • SqlAlchemyStore — PG / MySQL / SQLite / MSSQL; prod
  • RestStore — talks to remote MLflow server
  • Hot-path index: (run_uuid, key, step) on metrics
  • Schema migrations: Alembic under store/db_migrations/

Artifact backends

  • file:// → LocalArtifactRepository
  • s3:// / gs:// / wasbs:// / abfss://
  • dbfs:/ / databricks:// for DBFS / UC
  • 5-method contract: log_artifact(s), list, download, delete
  • Co-locate with serving region or pay round-trips

Async logging queue

  • Per-run worker thread; batches via log_batch
  • Flushed on end_run + atexit
  • SIGKILL can lose in-flight batch
  • Default ON; turn off only for one-shot scripts

Model packaging

  • MLmodel = YAML manifest + weights
  • Every flavor exports save_/log_/load_model
  • Almost all also register a python_function flavor
  • pyfunc.load_model(uri).predict(x) — universal
  • Always pass signature= + input_example=

Registry: stages vs aliases

  • Stages: legacy 4-state ladder (deprecated for new work)
  • Aliases: arbitrary mutable pointers; many per version
  • Promotion = re-point alias (no copy)
  • RBAC alias-write per environment
  • Consume as models:/X@champion — never version#

Serving

  • Pyfunc scoring server: Flask, POST /invocations
  • Payloads: dataframe_split/_records, instances, inputs
  • Signature validated before predict
  • Plugins: databricks, sagemaker, openai, mlflow
  • Pin URI at build time; never resolve aliases on hot path

Tracing

  • Span types: LLM, CHAIN, AGENT, TOOL, RETRIEVER, EMBEDDING, RERANKER, PARSER
  • Private TracerProvider — doesn't collide with user OTel
  • Buffer in TraceManager, finalised when root ends
  • Exporters: MLflow store / OTel / Inference Table

Auto-tracing

  • Pattern: safe_patch wraps SDK entry point
  • Convert to MLflow chat schema; emit typed span
  • Errors in our handler — WARN, never propagate
  • 14+ libs: OpenAI, Anthropic, LangChain, Bedrock, Gemini, Groq, Mistral, LiteLLM, CrewAI, Autogen, …
  • Use first-class callbacks (LangChain) over patching where available

ChatModel

  • Subclass of PythonModel; typed in/out
  • predict(ctx, msgs: list[ChatMessage], params) → ChatCompletionResponse
  • Inherits the entire tracking/registry/serving stack
  • Same Helm chart deploys agent and classifier

AI Gateway

  • Solves: provider lock-in, key mgmt, governance
  • Typed routes: chat, completions, embeddings
  • One adapter per provider in gateway/providers/
  • Provider swap = config change, not code

GenAI evaluation

  • Evaluation = rows; Assessment = per-row judgment
  • Judge = heuristic / LLM-as-judge / human
  • Closed loop: judge LLM call is also traced
  • Calibrate LLM judge vs human-rated set quarterly

Defaults that are usually right

  • Postgres for tracking
  • S3/GCS/Azure native to your cloud for artifacts
  • Async logging ON
  • Aliases over stages
  • Signature on every model
  • Gateway for any multi-provider work
  • Sampling on for prod traces

Anti-patterns

  • Logging into "Default" experiment
  • Hardcoding version numbers in prod code
  • Skipping signature=
  • Logging full datasets as artifacts
  • Tracking server exposed without auth
  • Unbounded agent loops
  • LLM-as-judge without calibration
  • PII in span attributes

Promotion ladder (recommended)

  • shadow alias — self-serve
  • challenger — team lead approval
  • champion — on-call sign-off
  • Enforced via alias-write RBAC
  • Rollback = re-point alias (seconds)

Stakeholder one-liners

  • DS: velocity
  • MLE: reproducibility
  • AI Eng: trace + eval
  • PM: time-to-value
  • SRE: SLOs + blast radius
  • Sec: secrets, PII, audit
  • Finance: per-team attribution
  • Legal: approved providers, explainability

End-to-end agent call

  • POST /invocations → ChatModel sig validate
  • Open root AGENT span
  • SDK calls auto-traced as LLM spans
  • Tool calls → TOOL spans
  • Root ends → TraceManager finalises → exporter ships
  • Trace lands in same experiment as the registered agent

Build vs buy — quick takes

  • W&B: small team, hosted, polished UI
  • SageMaker / Vertex: all-in on one cloud
  • LangSmith: LLM-only, no classical ML
  • BentoML / KServe: outgrown pyfunc scoring server
  • DVC: code-first reproducibility, no tracking server
  • MLflow: multi-cloud, full surface, self-host friendly

Interview cheat tells

  • "It depends on X" — not just "it depends"
  • Always name the tradeoff dimension
  • Mention failure modes, not just happy path
  • Defend a choice under "but what if…"
  • Reference primitives by name (AbstractStore, ChatModel)
